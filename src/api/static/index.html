Market Predictor API

Manual prediction console

Use this page to test the FastAPI backend without the React client. Enter a stock symbol and date, then call the `/predict` endpoint directly.

{}
GET /health
GET /predict?ticker=AAPL&date=2026-05-09
GET /predict/AAPL

Notes

The backend reads the latest feature window from `data/raw/yahoo/` and `data/processed/sentiment_hourly.parquet`.

If those files are missing, the API will return a helpful error message rather than crashing.
